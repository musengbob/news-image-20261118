One image summing up the world's news of Wednesday 18 November 2026: the Kerch Bridge strikes lead a front page of verified stories from Manila, London, the Bay of Bengal and the IPL. The front page is composed by compose.py (Pillow) from a fresh hero illustration, and main.ts copies the finished 1024x1024 image to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To rebuild the image from the hero illustration, run `python3 compose.py` first (needs Pillow).
